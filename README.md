# Arnav Kumar — Portfolio

Portfolio site for Arnav Kumar. Positioning: *Generalist Founding Operator*.

**Live:** [portfolio-arnav-kumar.vercel.app](https://portfolio-arnav-kumar.vercel.app)

## Stack

- React 19 (Create React App + craco) — *Phase 2: migrating to Next.js App Router with SSG for SEO + link-preview correctness.*
- TailwindCSS 3.4
- Shadcn UI components
- Lucide React icons
- Deployed on Vercel

## Local development

```bash
cd frontend
yarn install
yarn start
```

App opens at `http://localhost:3000`.
